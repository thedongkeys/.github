# .github

Org-level defaults for [@thedongkeys](https://github.com/thedongkeys).

The file that matters is [`profile/README.md`](profile/README.md) — GitHub renders it as the
organisation's public profile page. Edit it there, not here.

```
profile/
├── README.md          the org profile page
└── assets/
    ├── banner.png     1280×400 — lockup on ink
    └── herd.png       1280×281 — five Dongkeys
```

Anything else added to this repo (issue templates, `CONTRIBUTING.md`, workflow templates)
applies as a default across every repository in the org.
